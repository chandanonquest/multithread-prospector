# Apollo.io Prospecting Guidelines

When using Apollo.io MCP tools:
- **Search & Filtering**: Search organizations and contacts by specific titles, seniority, geography, company size, and technologies before performing enrichment.
- **Credit Efficiency**: Data enrichment (emails, phone numbers) consumes Apollo credits. Confirm target criteria before running bulk enrichment.
- **Sequences & CRM**: Check for existing records or sequences before adding new contacts to avoid duplicate outreach.
