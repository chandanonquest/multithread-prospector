# Contribution Guidelines

Thank you for contributing to the Autonomous B2B Prospecting Swarm!

## Workflow Process
1. Create a descriptive branch from `main` (`feat/...`, `fix/...`, `chore/...`).
2. Follow the security and operational conventions in `AGENTS.md`.
3. Verify that `python scripts/verify_no_secrets.py` passes cleanly before committing.
4. Submit a pull request detailing the changes and testing performed.
